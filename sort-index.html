How to Use Text Sorter

  • Apni lines Input box mein paste karein (ek line ek row).
  • 8 Modes mein se koi bhi click karein — instantly sort hoga.
  • A → Z: alphabetical ascending (apple, banana, cherry).
  • Z → A: alphabetical descending (cherry, banana, apple).
  • Length ↑: chhoti lines pehle (short → long).
  • Length ↓: lambi lines pehle (long → short).
  • Numeric: numbers ko sahi order mein (1, 2, 10, 100 — not 1, 10, 100, 2).
  • Reverse: lines ki tarteeb ulti.
  • Random: lines ko shuffle karein.
  • Advanced Options:
    • Case-Insensitive — A aur a same treat
    • Natural Sort — item2 before item10
    • Trim Lines — extra spaces hatayein
    • Remove Empty — khali lines skip
    • Remove Duplicates — repeated lines hatao
  • Auto-Process on hone par typing ke saath hi sort hoga.
  • Sort Summary mein dekhein kitni lines remove/skip hui.
  • Sab kuch client-side hai — aapka data kabhi server par nahi jata.
