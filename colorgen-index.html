How to Use Color Palette Generator

  • Generate New Palette button dabayein ya Space bar press karein.
  • Har color par lock icon se usse lock karein — locked colors regenerate nahi hongi.
  • Harmony Modes se different color theories apply karein (Analogous, Complementary, etc.).
  • Colors Count slider se 2 se 10 colors tak generate karein.
  • Saturation slider se muted ya vibrant palettes banayein.
  • Click on color to copy its hex code.
  • Undo/Redo buttons se previous palettes par jaayein.
  • Export section se CSS, Tailwind, JSON, PNG, SVG ya Text format mein download karein.
  • Save Current se apni favorite palettes save karein (localStorage mein).
  • Popular Palettes section se inspiration lein — click karke apply karein.
