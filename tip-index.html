How to Use Tip Calculator

  • Bill Amount enter karein ya quick preset chips ($10, $25, $50, $100, $200) se select karein.
  • Tip % set karein — either quick buttons (5/10/15/18/20/25%) se ya slider se.
  • Split Between se bill kitne logon mein divide karna hai wo choose karein.
  • Rounding option se final amount ko nearest dollar, round up, ya round down karein.
  • Advanced Options mein Tax % aur Discount % bhi add kar sakte hain.
  • Live Calculation — koi bhi value change karte hi result update hota hai.
  • Bill Summary mein: Bill, Tip, Tax, Discount, Total & Per Person amounts.
  • Bill Composition bar mein visual breakdown dekhein.
  • Tipping Guide se common scenarios ke liye tip percentages dekhein.
  • Copy Summary se formatted result copy karein.
  • Save button se calculation history mein save karein (localStorage).
  • Sab kuch client-side hai — aapka data kisi server par nahi jata.
