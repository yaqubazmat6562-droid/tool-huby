How to Use Currency Converter

  • Amount enter karein ya quick preset (1, 10, 100, 1K, 10K) se select karein.
  • From aur To currencies dropdown se choose karein.
  • Swap button se currencies exchange karein (⇄).
  • Exchange rate live fetch hoti hai Frankfurter API se (ECB data).
  • Result mein converted amount aur exchange rate dono dikhte hain.
  • Quick Conversions se popular pairs ek click mein convert karein.
  • Popular Rates mein 1 USD ke against 8 major currencies ke rates dekhein.
  • Conversion History local storage mein save hoti hai — last 20 conversions.
  • Refresh Rates button se latest rates dobara fetch karein.
  • Rates daily update hoti hain (ECB working days). Offline hone par cached rates use hote hain.
  • Sab kuch client-side hai — aapka data kisi server par nahi jata.
