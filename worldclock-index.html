How to Use World Clock

  • Hero Clock aapke local time ko live seconds ke saath dikhata hai.
  • Search bar mein city name type karein (jaise London, Tokyo, Dubai).
  • Filter chips se continents ke hisaab se cities filter karein.
  • Star icon par click karke cities ko favorites mein add karein.
  • 12H / 24H button se time format toggle karein.
  • Day/Night indicator batata hai ke wahan din hai ya raat.
  • Timezone offset aapke local time se difference dikhata hai.
  • Timezone Converter se do cities ke beech time convert karein.
  • Add Custom City se apne favorite timezone add karein.
  • Sab kuch client-side hai — koi data server par nahi jata.
  • Favorites aur custom cities localStorage mein save hote hain.
