How to Use Basic Calculator

  • Buttons par click karein ya keyboard use karein (numbers, +, −, *, /, Enter, Backspace, Escape).
  • C ya Escape se calculator clear hota hai.
  • ⌫ Backspace se last digit delete hoti hai.
  • % se percentage calculate karein (jaise 200 ka 10% = 20).
  • √ square root, x² square, 1/x inverse, π Pi value.
  • Memory buttons: MC (Clear), MR (Recall), M+ (Add), M− (Subtract), MS (Store).
  • Aapki calculation History mein save hoti hai — kisi bhi result par click karke use dobara use karein.
  • History browser mein localStorage se save hoti hai — refresh par bhi rehti hai.
