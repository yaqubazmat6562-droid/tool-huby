How to Use Simple Interest Calculator

  • 4 Modes: Calculate SI, Find Principal, Find Rate, Find Time.
  • Calculate SI Mode — Principal, Rate, Time enter karein → SI + Maturity milega.
  • Find Principal Mode — SI, Rate, Time enter karein → Principal milega.
  • Find Rate Mode — SI, Principal, Time enter karein → Rate milega.
  • Find Time Mode — SI, Principal, Rate enter karein → Time milega.
  • Time Unit Toggle — Years, Months, Days mein switch karein.
  • Live Calculation — koi bhi value change karte hi result update.
  • Donut Chart — Principal vs Interest ka visual breakdown.
  • Yearly Breakdown — Har saal ka interest aur cumulative total.
  • Compare Scenarios — Different rates/time ke saath comparison.
  • CSV Download — Breakdown export karein.
  • Copy/Save/Share — Result ko reuse karein.
  • Sab kuch client-side hai — koi data server par nahi jata.
