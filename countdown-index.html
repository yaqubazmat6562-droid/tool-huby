How to Use Countdown Timer

  • Do modes available: Duration (Hours:Minutes:Seconds) aur Until Date (specific date/time).
  • Duration Mode: Kitne ghante, minute, seconds ka countdown chahiye set karein.
  • Until Date Mode: Kisi bhi future date aur time ka countdown set karein.
  • Timer Label dein (optional) — jaise "New Year", "Meeting", "Exam".
  • Start Countdown button dabayein aur live ticking dekhein.
  • Pause/Resume button se timer rok sakte hain.
  • Reset button se timer ko restart karein.
  • Timer complete hone par alarm bajega aur notification milega.
  • Progress Ring visual mein countdown progress dekhein.
  • Quick Presets se common countdowns ek click mein set karein.
  • Save Timer — history mein save karein (browser localStorage).
  • Sab kuch client-side hai — koi data server par nahi jata.
